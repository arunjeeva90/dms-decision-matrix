# 14 — Calibration

Calibration domains:
- Camera intrinsics and distortion
- Camera-to-cabin extrinsics
- Driver seat and steering-wheel geometry
- Driver ROI and sanctioned gaze zones
- NIR exposure and illumination control
- Behavioral timing thresholds
- Confidence calibration
- Vehicle-signal mapping
- HMI escalation timing

Every calibration item shall have owner, unit, valid range, default, variant applicability, safety classification and change history.
