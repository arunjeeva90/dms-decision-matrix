# 08 — Regulations and Compliance

This register is a **traceability scaffold**, not a legal declaration of compliance. Applicability, revision, thresholds and test procedures require formal market-specific review.

| Reference family | Intended use |
|---|---|
| India DDAW / DMS-related AIS requirements | India homologation requirements and test methods |
| Bharat NCAP / AIS-197 | Consumer-rating and safety-assist alignment where applicable |
| EU General Safety Regulation | DDAW/ADDW product obligations for applicable vehicle categories |
| UNECE driver-control/assistance regulations | Driver engagement and assistance-system integration |
| ISO 26262 | Functional safety lifecycle |
| ISO 21448 | SOTIF lifecycle |
| ISO/SAE 21434 + UNECE R155/R156 | Cybersecurity and update management |
| ASPICE | Development process assessment |

See `compliance_matrix.csv` for requirement-to-evidence planning.
