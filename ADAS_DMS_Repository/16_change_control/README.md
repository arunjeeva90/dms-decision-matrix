# 16 — Change Control

## Baseline workflow
1. Raise change request with impacted requirement IDs.
2. Perform system, safety, SOTIF, cybersecurity, validation and calibration impact analysis.
3. Update requirements and trace links in one pull request.
4. Require domain review before approval.
5. Tag approved baselines (`dms-v0.1`, `dms-v0.2`, ...).

## Definition of Done
- Atomic requirements
- Parent and child traces
- Verification method and test link
- Safety/security/privacy impact recorded
- Diagrams updated
- Compliance register impact checked
