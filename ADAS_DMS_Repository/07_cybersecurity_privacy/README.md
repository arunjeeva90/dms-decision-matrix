# 07 — Cybersecurity and Privacy

| ID | Requirement | Verification |
|---|---|---|
| SEC-DMS-0001 | The platform shall verify authenticity and integrity of executable software, models and calibration packages before activation. | Security test |
| SEC-DMS-0002 | Cabin images and biometric-derived data stored outside volatile memory shall be encrypted and access controlled. | Audit/test |
| SEC-DMS-0003 | Debug and data-logging functions shall be disabled or access-controlled in production builds. | Inspection |
| SEC-DMS-0004 | The platform shall support secure rollback to a known-good model/software baseline. | Update test |
| SEC-DMS-0005 | Data collection shall implement purpose limitation, retention control, consent configuration and deletion workflow. | Privacy audit |
